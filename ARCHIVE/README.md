# ARCHIVE/

Каталог для устаревших документов и записей (I6).

## Правила

- Документы и записи не удаляются. Устаревшее перемещается сюда с указанием даты и причины.
- Формат имени: `YYYY-MM-DD-<оригинальное-имя>.md`
- В начале файла добавляется примечание:

```
ARCHIVED: YYYY-MM-DD
REASON: <причина архивирования>
SUPERSEDED BY: <ссылка на новый документ или запись, если применимо>
```

## Статус

Пока пусто. Первые архивные записи появятся при устаревании документов.
