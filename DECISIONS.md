- **Утверждающий:** [Архитектор / роль / агент]
- **Контекст:**
- **Решение:**
- **Основание:**
- **Последствия:**
- **Условие пересмотра:**
- **Связанные документы / записи:**
- **Заменяет (если superseded):** D-YYYYMMDD-XX

### D-20261013-01 — Выбор языка и формата выходного файла для nova-registry
- **Статус:** accepted
- **Дата:** 2026-10-13
- **Утверждающий:** Архитектор
- **Контекст:** Необходимо выбрать язык/инструмент для скрипта сбора снимков и формат выходного файла. Ограничение: без sudo, только прямой запуск.
- **Решение:** Использовать Python 3 (доступен на хосте `nova` как `/usr/bin/python3`, версия 3.12.3) и JSON как формат выходного файла снимка.
- **Основание:** Python проще обрабатывает рекурсивный поиск git-репозиториев в `~`, надёжнее управляет ошибками (например, `docker` без прав), удобно генерирует структурированный JSON. JSON — машиночитаемый, прост для парсинга, не требует внешних зависимостей (встроенный `json` модуль).
- **Последствия:** Скрипт пишется на Python 3 без сторонних библиотек. Выходной файл — `.json` с timestamp в имени, записывается в `records/`.
- **Условие пересмотра:** Если Python окажется недоступен в целевом окружении или JSON неудобен для последующей обработки.
- **Связанные документы:** docs/ARCHITECTURE.md, CURRENT_STATE.md, PROVENANCE.md (P-20261013-01 после проверки)
