### D-20261013-01 — Выбор языка и формата выходного файла для nova-registry
- **Статус:** accepted
- **Дата:** 2026-10-13
- **Утверждающий:** Архитектор
- **Контекст:** Необходимо выбрать язык/инструмент для скрипта сбора снимков и формат выходного файла. Ограничение: без sudo, только прямой запуск.
- **Решение:** Использовать Python 3 (доступен на хосте \`nova\` как /usr/bin/python3, версия 3.12.3) и JSON как формат выходного файла снимка.
- **Основание:** Python проще обрабатывает рекурсивный поиск git-репозиториев в ~, надёжнее управляет ошибками (например, docker без прав), удобно генерирует структурированный JSON. JSON — машиночитаемый, прост для парсинга, не требует внешних зависимостей (встроенный json модуль).
- **Последствия:** Скрипт пишется на Python 3 без сторонних библиотек. Выходной файл — .json с timestamp в имени, записывается в records/.
- **Условие пересмотра:** Если Python окажется недоступен в целевом окружении или JSON неудобен для последующей обработки.
- **Связанные документы:** docs/ARCHITECTURE.md, CURRENT_STATE.md, PROVENANCE.md (P-20261013-01 после проверки)

### D-20261013-02 — Фильтры полей docker и git, HTML-дашборд, .desktop, .gitignore
- **Статус:** accepted
- **Дата:** 2026-10-13
- **Утверждающий:** Архитектор
- **Контекст:** Требуется доработка nova_registry.py: фильтрация docker-полей, фильтрация git-репозиториев, генерация HTML-дашборда, .desktop-файл, обновление .gitignore.
- **Решение:**
  1. Docker: оставить поля ID, Image, Names, State, Status, Ports, RunningFor. Убрать Labels, Mounts, Command, CreatedAt, Networks, Platform, Size, LocalVolumes.
  2. Git: исключить пути, содержащие node_modules, .cache, venv, __pycache__, .git/modules.
  3. HTML-дашборд: генерировать records/latest.html после каждого снимка. Inline CSS, одна страница, без сервера.
  4. Favicon: records/favicon.svg.
  5. .desktop: ~/.local/share/applications/nova-snapshot.desktop, Terminal=false.
  6. .gitignore: добавить records/latest.html.
  7. UTF-8 в JSON: json.dump(..., ensure_ascii=False), locale C.UTF-8.
- **Основание:** Снижение объёма снимков, улучшение читаемости, удобство запуска.
- **Последствия:** nova_registry.py содержит фильтры и генерацию HTML. records/ содержит favicon.svg и latest.html.
- **Условие пересмотра:** Необходимость дополнительных полей docker или других фильтров git.
- **Связанные документы:** nova_registry.py, CURRENT_STATE.md, docs/ARCHITECTURE.md

### D-20261013-03 — Снимки records/*.json не в git
- **Статус:** accepted
- **Дата:** 2026-10-13
- **Утверждающий:** Архитектор
- **Контекст:** Вопрос о включении JSON-снимков в git.
- **Решение:** Не коммитить records/*.json. Коммитить records/README.md и records/favicon.svg. Снимки хранятся вне git.
- **Основание:** Снимки — производные данные, раздувают репозиторий. Код и документация — в git, данные — вне git.
- **Последствия:** records/*.json добавлен в .gitignore.
- **Условие пересмотра:** Изменение политики хранения первичных данных.
- **Связанные документы:** .gitignore, INVARIANTS.md (I3)
